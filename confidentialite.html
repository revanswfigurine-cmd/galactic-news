Privacy Policy

Galactic News publishing tool — last updated 8 September 2026.

Who this concerns

This tool has exactly one user: its owner. It collects no data about anyone else, and it is not accessible to the public.

What is stored

Only what is needed to publish on the owner's behalf:

  • the access and refresh tokens issued when the owner authorises the application;
  • the owner's account identifier and display name, used to confirm that content is published to the intended account;
  • the videos, images and text the owner has created.

Where it is stored

On a private server owned and operated by the owner. Credentials are written to files readable only by the account that runs the application. Nothing is sent to any third party, sold, shared, or used for advertising or analytics.

This site

These pages are static. They set no cookie, run no analytics, and store nothing. The authorisation page displays the one-time code returned by the platform so the owner can copy it into the private application; that code is never sent anywhere by this page.

Retention and deletion

Tokens are kept until the owner revokes the authorisation, in the platform's settings or by deleting them from the server, after which they are erased. The owner can delete all stored data at any time.

Contact

Requests concerning this tool can be sent to the address registered with the developer account that operates it.
